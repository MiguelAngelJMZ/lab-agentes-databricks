Laboratorio de Agentes en Databricks

Guía del participante · La Tinka · 26 de noviembre de 2026

ToolsMCPAgent BricksUnity Gateway2–3 horas

En el laboratorio construirás, paso a paso, un agente que responde preguntas sobre la mesa de servicio de TI: primero sus tools (una función de Unity Catalog y el Genie que ya conoces), después tu propio servidor MCP, luego el agente con memoria y, al final, su gobierno con Unity Gateway.

1. Elige cómo harás el Lab 3

Versión A · con tu laptop

Construyes el agente con el Agent Bricks CLI en tu terminal y lo pruebas en local antes de desplegarlo. Es el flujo de un desarrollador en su día a día.

Necesitas instalar tres cosas (sección 2).

Versión B · solo navegador

El mismo agente y el mismo CLI, pero corriendo dentro de un notebook de Databricks. No instalas nada.

Necesitas solo haber entrado una vez al workspace antes del día.

Si tu laptop corporativa no permite instalar programas o tiene proxy, elige la versión B. Los Labs 1, 2 y 4 son iguales en ambas.

2. Solo versión A: prepara tu laptop

2.1 Python 3.12+ y uv

# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
uv python install 3.12

# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
uv python install 3.12

2.2 Databricks CLI con login OAuth

# macOS
brew tap databricks/tap && brew install databricks
# Windows
winget install Databricks.DatabricksCLI

databricks auth login --host <URL del workspace> --profile tinka

Se abre el navegador para iniciar sesión. Los tokens personales (PAT) no sirven para este laboratorio: usa el login OAuth.

2.3 Agent Bricks CLI (Beta), versión 0.9.0

uv tool install databricks-agentbricks==0.9.0
agentbricks --version
agentbricks login --profile tinka

2.4 Verificación

  • python3 --version muestra 3.12 o superior
  • databricks current-user me --profile tinka muestra tu correo
  • agentbricks --version muestra 0.9.0
  • Un editor de código (VS Code, Cursor u otro)

3. El día del laboratorio

  1. Entra al workspace y abre Workspace → Users → tu correo → Lab Agentes La Tinka. Si no la ves, usa Workspace → Shared → Lab Agentes La Tinka.
  2. Abre 00 - Kickoff y verificación del ambiente, conecta Serverless y corre las celdas. Todo debe salir en ✓.
  3. Sigue los notebooks en orden: 01 → 02 → 03A o 03B → 04.
